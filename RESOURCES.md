# CS50 Screencast Resources

## Knowledge

- [CS50x Final Project specification](https://cs50.harvard.edu/x/project/)
  The only source that decides whether the submission passes. Use for: exact video
  length, the list of things the opening must display, README word count, submission
  steps. Re-read it before recording; everything else here is secondary to it.
- [How-To Geek: How to Record Your Screen](https://www.howtogeek.com/205742/how-to-record-your-windows-mac-linux-android-or-ios-screen/)
  Linked by CS50 itself from the project page, which makes it the sanctioned
  tool guide. Use for: picking a recorder per operating system.
- [OBS Studio documentation](https://obsproject.com/kb)
  Official docs for the free recorder we are using on Windows. Use for: setting up
  a display or window capture, adding a microphone, choosing output folder/format.
- [Microsoft: Record a video clip with Game Bar](https://support.microsoft.com/en-us/windows/record-a-video-clip-of-an-app-3c9dd2d5-0e4c-4bb4-9e6e-b0c66e2b2c0a)
  The zero-install fallback that ships with Windows. Use for: recording without
  installing anything, if OBS setup goes wrong the night before.

## Wisdom (Communities)

- [CS50 Discord / Ed](https://cs50.harvard.edu/x/communities/)
  The official CS50 community list. Use for: asking whether a specific submission
  detail passes, and watching what other students' final project videos look like.
- [r/cs50](https://www.reddit.com/r/cs50/)
  Active subreddit with staff presence. Use for: final project video questions,
  and searching past threads before asking (most video questions are already answered).

## Gaps

- No high-trust primary source yet on demo-video *craft* (pacing, narration, what to
  cut). Searches mostly return marketing-agency blog posts, which are sales content
  dressed as teaching. Best available substitute: watching three real CS50 final
  project videos on YouTube and noting what makes the good one good. Worth filling
  with a proper source (a university media-production guide) if this workspace continues.
