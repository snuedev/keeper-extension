# Teaching notes

## Preferences observed

- **Sabra checks claims.** When told voiceover was optional, the response was
  "Are you sure?" rather than acceptance. This is a good instinct — keep citing
  primary sources with verbatim quotes, and never assert a requirement from memory.
- Prefers plain language over jargon; wants the *why* behind a pattern, not just steps.
- Junior developer. Do not assume tooling or ecosystem conventions are known.

## Environment

- Windows with WSL2. WSL cannot record a screen — recorder must be a Windows app.
- The project README is unusually thorough and already explains the reasoning behind
  each design choice. It is the raw material for the script; do not make Sabra
  invent explanations that are already written down.
